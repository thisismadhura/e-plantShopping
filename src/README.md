
# Paradise Nursery

## Project Description

Paradise Nursery is a React-based online houseplant shopping application. Users can explore different categories of indoor plants, view prices, add plants to their shopping cart, and manage their orders.

## Features

- Home page with a Get Started button
- About Us section
- Three categories of houseplants
- Plant images, names, and prices
- Add to Cart functionality
- Dynamic shopping cart count
- Increase and decrease product quantities
- Remove products from the cart
- Automatic calculation of item totals and grand total
- Checkout Coming Soon message
- Continue Shopping option

## Technologies Used

- React
- React Router
- Redux Toolkit
- React Redux
- CSS

## Installation

1. Clone or download the project.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000` in your browser.
